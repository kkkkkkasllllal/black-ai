## M1：工程骨架、Autoload 单例、JSON 数据表与校验脚本
- **状态**：已通过 Godot 4.7.2 实机验收
- **目标**：建立标准 Godot 4 工程结构、输入映射、数据驱动单例与零报错自动化校验工作流。
- **核心交付物**：
  - 标准目录树：`autoload/`、`scenes/`、`scripts/`、`data/`、`dialogue/`、`assets/`、`docs/`、`tools/`；
  - `project.godot`（1280×720 窗口、WASD/方向键、E 交互、F 切换提灯、鼠标左键/Space 攻击、Esc 菜单，注册 `DataRegistry` / `GlobalMemory` / `GameState`）；
  - `AGENTS.md` 与 `docs/milestones.md`；
  - `autoload/DataRegistry.gd`、`autoload/GlobalMemory.gd`（持久化 `user://global_memory.json`）、`autoload/GameState.gd`；
  - `data/items.json`（6 档显卡、5 武器、6 消耗品、6 机箱、5 散热、3 系统提示词）、`data/characters.json`、`data/monsters.json`、`data/config.json`、`data/endings.json`；
  - `dialogue/` 对话模板、`scripts/utils/PlaceholderFactory.gd`、`scenes/boot/Boot.tscn` 自检场景；
  - `tools/validate_project.py` 自动化校验脚本。
- **独立验收方式**：
  1. 终端运行 `python tools/validate_project.py`，确认全部 JSON 校验、交叉引用与静态规则检查 0 报错。使用 `--godot <路径> --require-godot` 可指定引擎并要求通过全部 GDScript 的无头语法与类型检查；
  2. 在 Godot 4 中打开工程运行 `Boot.tscn`，核对面板加载数量：物品 31（显卡 6 / 武器 5 / 消耗品 6 / 机箱 6 / 散热 5 / 提示词 3）、核心 AI 娘 7、功能 NPC 5、怪物 6、结局 11；
  3. 依次点击自检面板按钮，确认 580 矿卡仅假小 C 接收 +12 / 强送 Gemini 猫猫 -5、上下文溢出与 PSU 清理缓存切换正常、读档后 `user://global_memory.json` 中 `sl_count` 持久递增。

## M2：2D 上帝视角探索原型
- **状态**：已通过 Godot 4.7.2 实机与输入验收
- **依赖**：M1
- **目标**：跑通暗黑探索核心手感——移动、提灯实时 2D 阴影与上下文溢出表里世界切换。
- **核心交付物**：
  - 使用 `TileMapLayer` 搭建的测试箱庭房间（地面层、带 `LightOccluder2D` 与碰撞的墙体层、隐藏血字 `TileMapLayer`）；
  - 玩家 `CharacterBody2D`（WASD/方向键 8 向平滑移动、纯色色块占位）；
  - 跟随鼠标旋转的扇形 `PointLight2D` 提灯 + `CanvasModulate` 暗环境 + `F` 键切换提灯亮度（常亮 / 调暗省存在感）；
  - 上下文溢出视觉表现：当 `GameState.is_context_overflow()` 为真时，隐藏血字图层显现、屏幕暗角/轻微抖动生效，附调试键切换上下文测试。
- **独立验收方式**：
  1. 按 `F5` 运行工程，点击「进入 M2」或按 `Enter`。也可打开 `ExplorePrototype.tscn` 后按 `F6` 单独运行。
  2. 用 WASD 或方向键贴着外墙、左上暗室门口、左下 L 型墙和四根机柜柱斜向绕行。确认碰撞阻挡可靠、贴边滑行顺畅，镜头跟随时保持在地图范围内。
  3. 在隔墙和机柜旁绕玩家移动鼠标。确认暖橘扇形提灯随指针转向，墙体和机柜后方出现实时阴影。按 `F` 来回切档，确认亮度、射程和 HUD 同步变化。
  4. 确认初始上下文为 100%，地板血字隐藏。按 `3` 或用 `1` / `[` 降到 ≤30%，确认血字显现并脉动，同时出现暗角、横纹和镜头微抖。再按 `3` 或用 `2` / `]` 升到 >30%，确认特效消退。
  5. 按 `Esc` 打开菜单，确认角色冻结。点击「继续探索」后可以移动，重新开菜单可返回 M1 自检面板。

## M3：巨型大 PSU 电源据点交互
- **状态**：已通过 Godot 4.7.2 严格校验与运行验收
- **依赖**：M2
- **目标**：实现核心据点【巨型大 PSU 电源】的完整交互闭环与经典手贱彩蛋。
- **核心交付物**：
  - 广场中央两层楼高纯色占位大 PSU 电源实体（暖橘指示灯，上下文溢出或击杀关键角色后切换红灯报警 + 电火花占位粒子）；
  - 正面 `E` 键交互菜单：【清理缓存】（上下文回稳至 80%、Token 回满、发出信号立刻刷新地图内普通暗影怪）、【升级血量】（消耗废弃权重碎片提升 HP 上限至最高 400）、【整理装备/背包】、【保存/读取存档】；
  - 背面隐藏交互点：红色物理总开关（`I / O`），连按 3 次直接触发假断电蓝屏与 5 秒搞笑彩蛋结局《手贱的代价》并登记至 `GlobalMemory`。
- **独立验收方式**：
  1. 按 `F5` 运行工程，按 `Enter` 进入探索。走到电源南侧正面按 `E` 打开据点菜单，按 `Esc` 或点击「离开电源」关闭。
  2. 靠近广场两侧的测试暗影怪，用鼠标左键或 `Space` 挥砍。确认击倒后获得碎片且上下文下降。按 `3` 降至 15%，确认电源红灯报警并冒出电火花。在电源菜单点击「执行清理缓存」，确认上下文回到 80%、Token 回满、小怪立即重生且电源恢复暖橘。
  3. 在暂停菜单领取 M3 测试碎片和示例装备。升级基础 HP 时每次增加 20 并扣除对应碎片，基础或有效上限达到 400 时禁用按钮。切到「整理装备 / 背包」穿卸四槽装备并使用硅脂，核对面板和上下文；在「保存 / 读取存档」测试槽 1 状态恢复和 SL 计数。
  4. 绕到电源北侧，在红色 `I / O` 开关旁按 `E` 三次。前两次出现提示和电火花，第三次触发黑屏及《手贱的代价》蓝屏，约 5 秒后恢复探索。按 `Esc` 返回 M1，核对已解锁结局中的 `joke_itchy_fingers`。
